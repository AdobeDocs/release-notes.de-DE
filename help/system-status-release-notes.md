# [!DNL Adobe System Status] – Versionshinweise {#status-release-notes}

[!DNL Adobe System Status] bietet detaillierte Informationen, Statusaktualisierungen und E-Mail-Benachrichtigungen zu Adobe-Produkten und -Diensten. Erhalten Sie Benachrichtigungen über Ausfälle, Störungen und Wartungsereignisse. Weitere Informationen dazu erhalten Sie unter [status.adobe.com/de](https://status.adobe.com/de/){target="_blank"}.

Auf dieser Seite werden [!DNL Adobe System Status] Aktualisierungen im Laufe der Zeit verfolgt. Sie wird nur aktualisiert, wenn es eine neue Version zum Reporting gibt.

| Datum | Updates |
| ------- | ------- |
| März 2026 | <ul><li>Virtueller KI-Assistent – Beta-Version</li><li>Fehlerbehebungen und Verbesserungen</li></ul> |
| &#x200B;8. Dezember 2025 | <ul><li>Verbesserungen beim Virtual Assistant Feedback (optimierte geführte Workflows, intuitive Symbole)</li><li>Fehlerbehebungen und Verbesserungen</li></ul> |
| &#x200B;16. Juli 2025 | <ul><li>Virtual Assistant – allgemeine Verfügbarkeit</li><li>Ereignis-ID-Suche auf Produkt- und Cloud-Seiten und im virtuellen Assistenten</li><li>Aktualisierung der Einrichtung von Slack-Benachrichtigungen</li><li>Fehlerbehebungen und Verbesserungen</li></ul> |
| &#x200B;20. März 2025 | <ul><li>Virtual Assistant – Betaversion</li><li>Neue Hilfeseite zum Ereignisglossar</li><li>Fehlerbehebungen und Verbesserungen</li></ul> |
| &#x200B;19. August 2024 | <ul><li>Produktbasierte Wartungsbenachrichtigungen (erweiterte Benutzeroberfläche und Benachrichtigungen pro Produkt)</li><li>Fehlerbehebungen und Verbesserungen</li></ul> |
| &#x200B;11. April 2024 | <ul><li>Abonnement-Hilfeseite zum Einrichten von Profilen und Voreinstellungen für proaktive Benachrichtigungen</li><li>Verbesserungen bei Benachrichtigungen (geschlossene CSO-Benachrichtigungen per E-Mail und Slack)</li><li>Fehlerkorrekturen</li></ul> |
| &#x200B;30. Januar 2024 | <ul><li>Ankündigungen sind jetzt Teil der Status-APIs</li><li>Leistungsverbesserungen an der Benutzeroberfläche</li></ul> |

| &#x200B;18. Juli 2023 | <ul><li>Ankündigungen: Globale Nachrichten, Nachrichten der Cloud- oder Produktebene mit großer Wirkung, jetzt als Abonnementoption verfügbar</li><li>Leistungs- und Abonnementverbesserungen</li><li>Fehlerbehebungen bei Benachrichtigungen</li></ul> |

| &#x200B;19. Januar 2023 | <ul><li>Statusbenachrichtigungen sind jetzt über die Adobe Status Slack-App in Slack verfügbar</li></ul> |
